Ik Core / Historia
Cronología del desarrollo

De las primeras pruebas a una plataforma documentada

Un registro de decisiones, versiones e intentos que marcaron el desarrollo del proyecto.

Origen

El proyecto comenzó con la necesidad de ejecutar una experiencia Super Game Boy completa: marco auténtico, comandos de paleta, audio SNES y compatibilidad con juegos como Nettou The King of Fighters ’96.

La rama NES Mini

Se ensayaron rutas con RetroArch y núcleos nativos. Las primeras mediciones mostraron que una cifra de 60 FPS en un benchmark no garantizaba que el juego completo fuera fluido. La investigación separó coste de BIOS, presentación de vídeo y ejecución tras la entrega al núcleo del juego.

La serie de optimizaciones llegó al hito Final #25, con rendimiento cercano a 60 FPS en modo directo posterior a BIOS según las pruebas registradas. Los resultados corresponden a escenarios específicos y no deben extenderse a todas las etapas de arranque.

Windows y Builder

En paralelo, se estructuró el formato SGBPACK1 para conservar una sesión reproducible y una herramienta de creación para Windows. El Builder adoptó una interfaz propia, validaciones del contenedor y el logotipo Ik Core aprobado.

Firmware SGB1

La experimentación con menús rediseñados mostró regresiones visuales y sonoras. Se decidió conservar los menús originales de Nintendo y estudiar los cambios de marco mediante intervenciones localizadas. La v0.19.5 sirvió como base de comparación para desarrollos posteriores.

Lecciones

La historia no es solo una lista de versiones: las compilaciones descartadas explican por qué la fidelidad del comportamiento original se volvió una restricción fundamental.
