# Ik Core — vista previa documental

Esta rama muestra un sitio de documentación estático en `docs-preview/` para revisar el diseño.

No modifica el emulador, el Builder ni los scripts de compilación. Tampoco distribuye ROMs, BIOS ni firmware propietario.

La página de prueba usa HTML y CSS locales y referencias técnicas públicas. Los PDF completos permanecen en el paquete de documentación preparado por separado; se incorporarán al sitio definitivo una vez aprobado el diseño.
