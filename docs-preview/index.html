Panorama del desarrollo

Ik Core es un proyecto independiente y no comercial dedicado a investigar, preservar y adaptar la experiencia Super Game Boy. El desarrollo reúne tres productos técnicos diferentes: emulador Windows, Builder SGBPACK1 y emulador standalone para NES Mini. El firmware SGB1 es una línea complementaria.

El objetivo de esta documentación es distinguir qué se implementó, cómo se investigó, qué se validó y qué quedó experimental.

Estado editorial, octubre de 2026: los firmwares posteriores elaborados mediante Codex fueron reportados como funcionales, pero esta edición no atribuye detalles internos que aún no están acompañados de código o registros de prueba auditables.

El principio de Ik Core

Conservar los gráficos, comandos SGB, marcos y sonidos cuando son parte de la experiencia original, optimizando solamente lo que pueda medirse sin introducir regresiones.
