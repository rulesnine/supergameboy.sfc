Ik Core para Windows

La plataforma donde se construyen y verifican sesiones SGBPACK1 con el motor adaptado.

Base técnica

El proyecto documenta una implementación basada en Snes9x / SuperSnes9x, cuya procedencia y licencias deben mantenerse explícitas. El emulador está orientado a Windows x64.

Flujo de trabajo

  1. Preparar los componentes obtenidos legalmente por el usuario.
  2. Crear la sesión con el Builder.
  3. Validar cabeceras, longitudes e integridad.
  4. Ejecutar la sesión en Ik Core.
  5. Comprobar imagen, audio, entrada, marcos y persistencia cuando corresponda.

Compatibilidad

Las pruebas de KOF ’96 han servido para verificar comandos Super Game Boy y marcos dinámicos. La documentación distingue una ROM de referencia de los archivos integrados en el contenedor.

Construcción

Consulta las instrucciones y el flujo automatizado del workflow de Windows y el repositorio de código.
