# Ik Core — Credits and acknowledgements

Ik Core is an **unofficial derivative project**. Its new identity does not replace or obscure the origin of the emulator code on which it is based.

## Base projects

- **Snes9x** — portable Super Nintendo Entertainment System emulator. The project was founded by Gary Henderson and Jerremy Koot and has received contributions from many developers over its history.
- **SuperSnes9x** — unofficial Snes9x fork maintained in the `shanytc/snes9x` repository. Ik Core uses commit `183e03e5efed3b6d450385c98e2ccffb194153c3` as its pinned technical base.
- **libretro / RetroArch** — optional Windows libretro interface and ecosystem used by the project.
- The wider Game Boy, Super Game Boy, SNES emulation, preservation and reverse-engineering communities whose public technical work made interoperability research possible.

## Ik Core additions

Ik Core adds and maintains the SGBPACK1 single-file loading path, validation and routing needed to mount an embedded Super Game Boy program ROM, Game Boy cartridge ROM and SGB boot ROM as one package, plus Ik Core branding and Windows packaging.
