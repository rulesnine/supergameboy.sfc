# Ik Core branding

Official product name: **Ik Core**

Technical subtitle: **SGBPACK Runtime for Windows**

Official executable: `IkCore.exe`

The visual identity is deliberately minimal: a white rounded-square icon with black **Ik / Core** typography. It is independent from Nintendo, Snes9x and SuperSnes9x artwork.

The product should be described as:

> Ik Core is an unofficial and independent Windows emulator derived from SuperSnes9x/Snes9x, adapted to load Super Game Boy sessions packaged in a single SGBPACK1 file.

Do not describe Ik Core as an official Nintendo product or as wholly original emulator code. Preserve upstream attribution and license notices in every distribution.
